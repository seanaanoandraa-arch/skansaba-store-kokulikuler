SKANSABA STORE - VERSI REDESAIN TANPA ADMIN

Cara menjalankan:
1. Ekstrak folder toko_skansaba.
2. Buka folder tersebut di Visual Studio Code.
3. Jalankan index.html menggunakan Live Server.

Halaman:
- index.html       : Beranda
- katalog.html     : Katalog produk, pencarian, dan filter kategori
- keranjang.html   : Keranjang dan checkout simulasi
- tentang.html     : Informasi tentang toko
- kontak.html      : Formulir dan informasi kontak

Fitur pengunjung:
- Menampilkan produk
- Pencarian produk
- Filter kategori
- Menambahkan produk ke keranjang
- Mengubah jumlah dan menghapus barang dari keranjang
- Checkout simulasi

Catatan:
Data keranjang, produk, dan pesanan demo disimpan di localStorage browser.
Checkout belum mengirim pesanan ke server atau database. Form kontak juga
hanya menampilkan konfirmasi pada halaman dan belum mengirim pesan sungguhan.

Folder admin dan fungsi pengelolaan produk oleh admin tidak disertakan.
